About

Hi, I’m Alienkrishn, also known as Anon4You — a self-taught Linux and shell scripting enthusiast from India. I learn by breaking things and rebuilding them better, mostly inside Termux.

🛠️ What I maintain

TermuxVoid is my unofficial package repository for Termux: 250+ security, Android, AI and utility tools that are missing from the official repos. The same packages ship as both an APT (dpkg) and a Pacman repository, compile natively for Android, and are licensed BSD-3-Clause.

It replaced my old alienkrishn repository, which is now archived — every tool moved to TermuxVoid.

  • 📦 APT repository · Pacman repository
  • 🧰 Package catalog
  • 📲 Setup and tool browser

🚀 Pinned projects

  • flutter-termux — run Google’s Flutter SDK directly on Android with Termux.
  • Laudacode — a fast, lightweight AI coding agent for the terminal, pure Rust and built for Termux.
  • Qrylz — patch an Android APK so signature verification keeps working after re-signing, without duplicating the APK.
  • dex2c — Dalvik-to-C++ JNI compiler for Termux: turns Java/Kotlin methods into native JNI code inside the APK.
  • termux-penv — install and manage 32-bit/64-bit Termux chroot environments for cross-compilation and multi-arch testing.
  • InstaGhost — simple, professional Instagram data gathering.
